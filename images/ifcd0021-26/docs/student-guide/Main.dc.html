Student guide

From clone to upload

The practical exam uses two existing branches: backend (the boot/ Spring Boot project, activities 1–4) and frontend (the react/ project, activity 5). Clone once, switch to a branch, fill in the gaps, zip it, and upload it to the matching form. Seven steps, no branches to create.

backend · boot/ · MF01, MF02, MF03, MF04 frontend · react/ · MF05
1

Clone the repo

Do this once. You get the starter on master, plus the backend and frontend branches. Repo: github.com/AlbertProfe/ifcd0021-26-prova-practica

git clone https://github.com/AlbertProfe/\ ifcd0021-26-prova-practica.git cd ifcd0021-26-prova-practica
2

Switch to a branch

Pick backend (activities 1–4 in boot/) or frontend (activity 5 in react/). Don't create a branch yourself: everyone starts from exactly the same code.

git switch backend # for the frontend: git switch frontend
3

Read your branch's part of the README

Open the root README.md. It describes all five activities. On backend, work through activities 1–4 (MF01 Git, MF02, MF03, MF04 including Postman). On frontend, do activity 5 (MF05).

README.md backend → boot/ (activities 1–4) frontend → react/ (activity 5)
4

Fill in the gaps

Complete the missing parts of the code as the README describes. On each branch, also create a doc/ folder at the repo root with a Markdown file for notes, images and screenshots. On backend, put the public Postman collection link in that Markdown — not on the exam paper.

// TODO: your code here # also create: doc/exercicis.md
5

Commit your work

The zip only contains committed files, so commit first — including the doc/ folder (Markdown, screenshots; on backend, the Postman public link).

git add -A git commit -m "backend exercises"
6

Zip it with git archive

Use the form's exact format. No accents in the name. The -1 is part of the format, not optional. Because it comes from git, node_modules and target stay out.

git archive --format=zip \ -o MF01-04_PP_Nom_Cognom1_Cognom2-1.zip backend git archive --format=zip \ -o MF05_PP_Nom_Cognom1_Cognom2-1.zip frontend
7

Upload it to the Google Form

Two forms, one zip each. Upload the backend zip to the MF01-04 form and the frontend zip to the MF05 form, in the Prova Pràctica field (not Avaluació Continuada). MF04 (REST and Postman) is graded from the backend zip. MF05 is graded from the frontend zip. Doing both? Switch branch and repeat from step 2.

MF01-04-Prova_Pràctica → MF01-04_PP_…-1.zip MF05-Prova_Pràctica → MF05_PP_…-1.zip

Name your zip

The form's format: the prefix, then Nom_Cognom1_Cognom2, then -1. No accents. The -1 is part of the format.

MF01-04_PP_Emma_Alonso_McCoy-1.zip
MF05_PP_Emma_Alonso_McCoy-1.zip

What the form looks like

Two Google Forms, one Prova Pràctica field each. Use that field, not Avaluació Continuada.

MF05-Prova_Pràctica MF05_PP_Emma_Alonso_McCoy-1.zip

No branches to create

You only switch to an existing branch: backend or frontend.

Same code for everyone

Every student starts from exactly the same files.

Two forms, two zips

Backend zip → MF01-04 form. Frontend zip → MF05 form. MF04 is graded from the backend zip. MF05 is graded from the frontend zip.

Zip is empty or missing your changes?

git archive only includes what you committed — including doc/. Run git status: if it lists changed files, repeat step 5 and then zip again.
