Product ×3ConsumesuseContext, then calls setCount(c => c + 1). It never reads count.Yes, the context value is a new object each time
CartSummaryConsumesuseContext, reads count to show it and calls setCount(0) on Clear.Yes
  • Siblings share state without props. Product in one branch updates CartBadge in the other.
  • Header, Main and ProductList never re-render. They don't call useContext, and their children are unchanged elements.
  • Every consumer re-renders on any change. Product only uses setCount, yet its counter still goes up, because the context value is a new object each time.
